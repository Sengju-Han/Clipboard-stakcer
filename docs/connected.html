Put this in the repository as a secret called GOOGLE_REFRESH_TOKEN:

Settings → Secrets and variables → Actions → New repository secret. Add GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET there too, if you have not already.

Then run Check Google Drive once. It puts one small file in the folder and says whether that worked — half a minute, and it is the only way to be sure without waiting for a whole export.

This is a key to the files this app makes in your Drive. Treat it the way you would a password: paste it into the secret, then close this tab. If it ever gets out, revoke it at myaccount.google.com/permissions.
