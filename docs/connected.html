Connecting Google Drive

Reading what Google sent back…

  1. Go to Actions → Connect Google Drive → Run workflow.
  2. Paste the code into code.
  3. Run it. It swaps the code for a lasting connection and stores it as a secret — the code itself is used once and is no good to anyone after that.

This page is only ever handed a one-time code. It has no access to your Drive and sends nothing anywhere: the code sits in the address bar, and copying it is the whole job.
