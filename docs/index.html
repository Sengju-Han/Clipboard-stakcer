Settings

Both keys are kept in this browser only. The GitHub token is sent to api.github.com and the Anthropic key to api.anthropic.com, each to nowhere else. Neither reaches this page's source, the repository, or anyone else. Clear either by emptying its box and adding a card, or by clearing this site's data.

A key held in a browser is only as private as the device holding it, so it is worth giving the Anthropic key a spend limit in the Console. Leave the box empty and lookups go through a workflow instead: slower, but nothing is stored here.
