## Anki deck export
This repository carries a GitHub Actions workflow that exports a deck from your AnkiWeb account (words, scheduling, and review ratings) to CSV/JSON without installing anything locally. See **anki/README.md**.

## Anki TTS package
A second workflow generates neural audio for a field and packages it as an `.apkg` that updates your existing notes in place, leaving review history and FSRS scheduling untouched. See **anki/TTS.md**.

## Add cards from your phone
A web form that adds a card to your collection and generates its sentence audio on the way, so nothing has to be imported. See **anki/ADD-CARD.md**.
